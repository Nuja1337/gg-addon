Guild Golem Sync check

Two questions for the Guild Golem addon's Sync, answered in Chrome or Edge with the game running. Nothing leaves your computer. This page reads the two files you pick, and writes only the probe's own Data.lua.

Chrome and Edge can't open files under Program Files, where the game installs by default. If your game is there, these checks can't run, since a copy of the files somewhere else isn't the one the game writes and reads (docs/RESEARCH.md, "Probe results").

1. Can the browser read the game's saved file while the game runs?

Pick WTF\Account\<your account>\SavedVariables\GuildGolemProbe.lua in your game folder. Then /reload in game, or log out: the page should say the file changed a few seconds later.

2. Does a reload read a file the browser rewrote?

Pick Interface\AddOns\GuildGolemProbe\Data.lua and press Write. Then /reload in game and type /ggprobe: the reload test line should say "by the browser" and the time below.
